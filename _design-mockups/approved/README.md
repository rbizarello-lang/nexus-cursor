# Telas aprovadas (referência visual)

Guarde aqui prints ou HTML estáticos das telas do NEXUS que você **aprovou** após um refino de layout.

O agente e a skill `/refine-layout` usam estes arquivos como âncora de “como deve parecer”, em complemento a `_design-mockups/` (exploração / P1…).

## Como adicionar

1. Após validar no clássico ou na Demo, capture a viewport relevante.
2. Salve com nome descritivo, por exemplo:
   - `demo-hoje-mar.png`
   - `classic-intimacao-card.png`
   - `demo-operacao-briefing.png`
3. Opcional: uma linha neste README dizendo edição + tema + o que ficou certo.

## Não colocar

- Experimentos rejeitados (deixe em `_design-mockups/` ou descarte)
- Dados sensíveis legíveis em prints de produção — prefira dados de teste ou crop
